How to install and play!

First off, you need to have a python interpreter. You can vist python.org, or another option is to use Spyder.

Note: If you use the python.org interpreter you will also need to download an IDE. If you have a windows device you can use Microsoft Visual Studio Code

Next you will need the program its self. You can visit the GitHub Repository and find the .py and the .json files. Make sure to download them to the same folder!

The next part is very simple, all that you need to do is open the downloaded python file (.py) in the interpreter and run the program!
